# Roadmap

## v0.1 — Initial public alpha

- `$pro-architect` Codex skill
- local dependency-free stdio MCP server
- plan, review, consult, and status tools
- GPT-5.6 Pro Responses API loop
- bounded read-only repository inspection
- token usage and estimated-cost ledger
- CLI setup, doctor, and registration commands
- security and end-to-end mocked API tests

## v0.2 — Durable project architecture

- opt-in project session identifiers
- resume/reset/status lifecycle
- prompt and model version pinning
- encrypted or user-controlled local session metadata
- structured plan artifact schema
- explicit save handoff to outer Codex

## v0.3 — Evaluation and routing

- compare standard versus Pro mode on the same planning task
- record latency, cost, evidence coverage, and user verdict
- policy-driven effort selection
- project and monthly budget reporting
- architecture-drift review between plan and diff

## v0.4 — Cross-repository planning

- explicit multi-root workspaces
- independent access policy per repository
- protocol and compatibility sequencing across services
- coordinated sprint output

## Validation backlog

- Windows installation and path semantics
- current Codex desktop MCP protocol compatibility matrix
- long-running Pro timeout behavior
- cancellation during model and local-tool phases
- large monorepository benchmarks
- OpenAI organization/project budget integration
